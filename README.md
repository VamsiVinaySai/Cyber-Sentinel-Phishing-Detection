# 🛡️ Cyber Sentinel: AI-Based Phishing Detection

An AI-powered tool that analyzes URLs in real-time to detect phishing attempts. It uses a Random Forest classifier to examine URL structure (length, special characters, IP usage) and flag potential threats.

## 🚀 Features
- Real-time URL analysis
- Machine Learning (Random Forest) backend
- Visual Dashboard using Streamlit
- Extracts 8+ lexical features from URLs
